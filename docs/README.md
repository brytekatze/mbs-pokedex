## Plantilla de documento

Todo nuevo documento debe incluir, como mínimo:

1. **Objetivo**
2. **Cambios realizados**
3. **Archivos afectados**
4. **Decisiones técnicas**
5. **Cómo verificar / probar**
6. **Pendientes**

Ver sección 5.1 de [`AGENTS.md`](../AGENTS.md) para las reglas completas.
